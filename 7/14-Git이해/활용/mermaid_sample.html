Mermaid.js 다이어그램 샘플

1. 순서도 (Flowchart)

flowchart TD
    A[시작] --> B{비밀번호 검증}
    B -- 성공 --> C[로그인]
    B -- 실패 --> D[에러 메시지]
    D --> B
    C --> E[종료]

2. 시퀀스 다이어그램 (Sequence Diagram)

sequenceDiagram
    participant User
    participant Client
    participant Server
    User->>Client: 비밀번호 입력
    Client->>Server: 로그인 요청
    Server-->>Client: 검증 결과
    Client-->>User: 결과 표시

3. 클래스 다이어그램 (Class Diagram)

classDiagram
    class PasswordValidator {
      +str pattern
      +is_valid_password(password) bool
    }
    class User {
      +str password
      +login()
    }
    User --> PasswordValidator : 검증 요청
