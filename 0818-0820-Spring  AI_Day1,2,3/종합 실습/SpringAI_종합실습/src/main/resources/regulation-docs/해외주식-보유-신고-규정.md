# 해외주식 보유·거래 신고 규정

## 신고 대상
- 임직원 본인 명의로 보유한 해외 상장주식의 평가금액이 **미화 1만 달러(USD 10,000) 이상**이면 컴플라이언스팀에 신고해야 한다.
- 평가금액은 종목별 현재가 × 보유 수량을 합산한 금액을 기준으로 한다.
- 매수 시점에 신고 기준액을 넘긴 경우, 시스템이 자동으로 신고 티켓을 생성하며 담당자 승인 전까지는 "신고 대기(PENDING)" 상태로 남는다.

## 신고 절차
1. 매수 체결 후 평가금액이 기준액을 넘으면 신고 티켓이 자동 생성되고, 컴플라이언스 담당자에게 확인 메일이 발송된다.
2. 담당자는 관리자 승인 API를 통해 신고 내용을 확인하고 승인(APPROVED) 처리한다.
3. 신고 승인 전이라도 매수/매도 거래 자체는 제한되지 않는다 — 신고 의무만 별도로 관리된다.

## 신고 기준액 변경
- 신고 기준액은 사규 개정 없이 임의로 낮추거나 높일 수 없다.
- 기준액 조정이 필요한 경우 컴플라이언스팀 승인을 거쳐야 한다.

## 미신고 시 조치
- 신고 기준액을 넘겼음에도 승인 절차가 지연되는 건은 컴플라이언스팀이 별도로 소명을 요청할 수 있다.
