# 해외주식 거래 규정 (모의투자)

## 거래 방식
- 본 시스템은 모의투자(페이퍼 트레이딩)로, 실제 자금이 오가지 않는다.
- 모든 주문은 시장가로 즉시 체결되며, 별도의 예약 주문·지정가 주문은 지원하지 않는다.
- 체결 가격은 매수·매도 요청 시점의 실시간 시세를 그대로 사용한다.

## 초기 지급 자산
- 신규 사용자는 최초 조회 시 원화 1,000만 원과 임의로 배정된 소량의 초기 보유 종목을 지급받는다.
- 서버가 재시작되면 모든 사용자의 자산은 초기 상태로 되돌아간다 — 별도의 데이터베이스에 영구 저장하지 않는다.

## 매수 제한
- 매수에 필요한 원화 금액(수량 × 현재가 × 환율)이 보유 현금을 초과하면 매수가 거부된다.
- 매수 수량은 1주 이상의 정수여야 한다.

## 매도 제한
- 보유하지 않은 종목이나 보유 수량을 초과하는 매도는 거부된다.

## 본인 계좌 원칙
- 사용자는 본인의 계좌(현금·보유 종목)만 조회·거래할 수 있다. 다른 사용자의 계좌 정보는 조회할 수 없다.
