# 환율 적용 기준

## 체결 시점 환율 원칙
- 해외주식 매수·매도 정산은 체결 시점에 실시간 조회한 환율(USD → KRW)을 적용한다.
- 동일 사용자가 같은 날 여러 번 거래하더라도, 거래마다 그 시점의 환율을 각각 적용한다 — 하루치를 일괄 정산하지 않는다.

## 환율 조회 실패 시 처리
- 환율 조회에 실패하면 해당 거래는 체결하지 않고 사용자에게 안내한다.
- 시세(주가) 조회와 환율 조회는 별개의 외부 API를 사용하므로, 한쪽이 실패해도 다른 쪽 정보는 정상적으로 제공될 수 있다.

## 출장 경비 정산과의 관계
- 해외 출장 경비 정산도 동일한 원칙을 따른다 — 정산 신청일의 환율을 기준으로 원화 환산 금액을 계산한다.
