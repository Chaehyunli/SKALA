# 반품·교환 정책

## 반품·교환 가능 기간
- 단순 변심에 의한 반품·교환은 상품 수령일로부터 7일 이내에 신청해야 한다.
- 상품 하자 또는 오배송의 경우 상품 수령일로부터 30일 이내에 신청할 수 있다.

## 배송비 부담
- 단순 변심으로 인한 반품·교환은 왕복 배송비를 고객이 부담한다.
- 상품 하자 또는 오배송으로 인한 반품·교환은 배송비를 판매자가 부담한다.

## 반품 불가 상품
- 포장을 개봉한 식품류
- 고객 요청에 따라 제작된 맞춤 제작 상품
- 사용 흔적이 있는 상품

## 환불 소요 기간
- 반품 상품이 판매자에게 도착하여 상태 확인이 완료된 후 3영업일 이내에 환불이 처리된다.
- 환불은 최초 결제 수단으로 진행된다.
